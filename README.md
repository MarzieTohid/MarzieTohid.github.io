# Personal Portfolio

A clean, responsive personal portfolio website prepared for GitHub Pages.

## Files

- `index.html` — main page
- `css/style.css` — website design
- `js/script.js` — mobile menu and small interactions
- `images/` — profile/project images
- `documents/` — CV and certificates
- `assets/icons/` — custom icons

## GitHub Pages

Create a repository named:

`YOUR-USERNAME.github.io`

Upload all files and folders while keeping the same structure.

Then go to:

Settings → Pages → Deploy from a branch → main → / (root) → Save

Your website will be available at:

`https://YOUR-USERNAME.github.io`
